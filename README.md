# MY TRIP starter

Responsive travel-planner prototype.

## Deploy to Netlify
1. Create a GitHub repository named `my-trip`.
2. Upload `index.html` to the repository root.
3. In Netlify choose **Add new site → Import an existing project**.
4. Connect GitHub and select `my-trip`.
5. Leave Build command blank and set Publish directory to `.` then deploy.

New trips are currently saved in this browser only. Supabase, authentication and live maps are not connected yet.
